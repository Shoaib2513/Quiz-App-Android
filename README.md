# 📱 Android Quiz App

A Quiz App built using Android Studio that allows users to answer multiple-choice questions and view their final score.

---

## 🚀 Features
- Multiple choice quiz questions
- Score tracking system
- Simple and clean UI
- Instant result display
- Restart quiz option

---

## 🛠 Tech Stack
- Java / Kotlin
- Android Studio
- XML for UI design
